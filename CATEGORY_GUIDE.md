# Category Guide

The project uses these categories for prioritization and message tailoring.

| Category | Meaning | Outreach angle |
| --- | --- | --- |
| `public_student_union` | Studierendenwerk / student-union residences | Apply through official process; ask about hardship, Nachrücken, waiting list, and document completeness. |
| `catholic_church` | Catholic church, Catholic foundations, Kolping, Caritas, religious orders | Respect community profile; ask about motivation letter, reference, and house-life expectations. |
| `protestant_church` | Protestant / Evangelische residences and associations | Emphasize community fit and readiness to participate. |
| `ecumenical_christian` | Ecumenical or interreligious residences | Emphasize openness, respectful community living, and academic seriousness. |
| `christian_other` | Other Christian carriers such as CVJM | Ask about community rules and eligibility honestly. |
| `youth_housing` | Jugendwohnen / youth houses | Check age limits and whether students are accepted. |
| `social_nonprofit_association` | Foundations, associations, and nonprofit residences | Ask about waiting list, documents, and selection criteria. |
| `commercial_private` | Private/commercial operators | Ask about immediate availability, cheaper room types, temporary offers, and flexible start dates. |
| `municipal` | City-run housing | Ask about local eligibility and waiting list. |
| `specialized_field` | Field-specific housing | Apply only if you fit the listed field/gender/age criteria. |
| `short_term` | Hostels/temporary fallback | Use only as a bridge while applying elsewhere. |
| `other_unknown` | Needs manual review | Check source and reclassify if useful. |
